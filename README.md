# Project Graduation · Hillsborough High School

Brand assets and website for Project Graduation, the fundraising program behind Hillsborough High's all-night grad celebration.

- `website/`: the site (home, events, sponsor sign-up, admin console) and its Python server. See [website/README.md](website/README.md) to run it.
- Root PNGs: original logo files (mascot, wordmarks, geometric mark, pattern).
